# LN2 Manager

Downloads of the LN2 Manager program for Windows. This repository contains no
source code.

## Install

1. Open the latest release (under **Releases** on this page) and download
   `LN2-Manager-vX.Y.Z-windows.zip`.
2. Unzip it somewhere you can save files, such as Documents or `C:\LN2 Manager`
   (not Program Files).
3. Double-click `LN2Manager.exe`. If Windows says "Windows protected your PC",
   click **More info**, then **Run anyway**.

Installed copies update themselves from this page, so there's nothing else to
download later. `README.txt` in the download covers where your data is kept and
how to start the app automatically when you log in.
